# AI-Voice-Notes-Pro
A professional-grade AI transcription tool built with Python and OpenAI's Whisper model.

## Description
This application allows users to transcribe audio files locally and privately. It features a modern interface, a smart history sidebar, and context-aware transcription settings.

## Prerequisites
Before running the application, ensure you have **Python 3.9+** installed on your system.

## Installation
To run this project locally, follow these steps:

1. **Install Python dependencies:**
   ```bash
   pip install openai-whisper customtkinter
2. Install FFmpeg (Required for audio processing):
    Windows: winget install ffmpeg
    macOS: brew install ffmpeg
    Linux: sudo apt install ffmpeg
3. How to use
Once the dependencies are installed, follow these steps:
Download the code:
    Clone this repository or download the AIGenerator.py file.
Run the application:
    python AIGenerator.py
Select an audio file:
    Choose a file (.mp3, .wav, or .m4a) and click on the transcription button.
